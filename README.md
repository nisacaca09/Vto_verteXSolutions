# VTO — verTexsOlution Company Profile

Modern company profile website for **VTO (verTexsOlution)**, an IT consulting and software development company.

## Tech Stack

* Next.js 16
* React 19
* TypeScript
* Tailwind CSS 4
* Framer Motion
* Lucide React
* shadcn/ui

## Features

* Responsive company profile website
* Service showcase pages
* Portfolio section
* Contact page
* Authentication mockup pages
* Admin / Dashboard mockup
* SEO metadata support
* Modular component-based architecture
